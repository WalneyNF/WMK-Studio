2. Instalar a logo aprovada

  1. Baixe a logo aprovada nesta conversa como arquivo PNG.
  2. Salve uma cópia em D:\Ferramentas\figcraft\wmk-logo.png.
  3. Abra o CMD e execute:
cd /d D:\Ferramentas\figcraft
python wmk-instalar-logo.py

O script usa Pillow (já encontrado no Python instalado nesta máquina), redimensiona PNGs para os tamanhos utilizados pelo app, gera um ícone .ico e cria uma cópia de segurança dos ícones originais em assets\app-icon\backup-figcraft-original. O script não deve ser executado sem o PNG correto.

3. Português brasileiro

O código contém catálogo crates/ui-egui/locales/pt-BR.toml. O menu de idioma foi verificado em crates/ui-egui/src/dialogs.rs, na janela Preferências → Idioma (em inglês: Preferences → Language).

  1. Abra o menu que contém Preferências ou a janela de configurações do aplicativo.
  2. Na janela Preferências, encontre o seletor Idioma.
  3. Escolha Português (Brasil).
  4. Se continuar em inglês, confirme se está executando a versão nova e se existem traduções faltantes.

O padrão de novas preferências foi alterado para pt-BR em crates/engine/src/prefs.rs. Para quem já possui configurações persistidas, a escolha anterior pode continuar; nesse caso mude manualmente nas preferências. A documentação do projeto diz que a alteração de idioma passa a valer imediatamente.

4. Compilar e encontrar o novo executável

cd /d D:\Ferramentas\figcraft
wmk-compilar.cmd

Se o Cargo terminar com sucesso, o script cria target\release\WMK-Studio.exe a partir do binário do pacote figcraft, que permanece com o nome interno original para reduzir problemas de dependências.

ATENÇÃO: alteramos o código, mas a nova versão não foi confirmada como compilada, nem houve teste visual completo. Os PNGs e o .ico novos só aparecerão na versão recompilada depois da instalação da logo. Verifique com um documento de teste .wmk antes de migrar projetos antigos.

5. Primeiro exercício

  1. Na tela inicial, escolha Novo arquivo de design.
  2. Pressione F, arraste para criar um quadro.
  3. Selecione o quadro e altere W, H e Preenchimento no inspetor.
  4. Adicione objetos e texto, teste salvamento como primeiro-app.wmk.
  5. Feche e reabra o documento para confirmar que persistiu.
