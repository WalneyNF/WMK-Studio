WMK Data Studio 0.2 — Importação WMK Studio

Abra projetos .wmk e visualize telas e componentes dentro do gerenciador SQLite

Walney Moreira Klein — walneyk@hotmail.com | 08/11/2026

Central de Manuais | Data Studio SQLite

1. O que a nova aba faz

O visualizador lê document.json do arquivo .wmk, detecta os Frames principais, monta uma prévia HTML experimental, mostra a árvore de nós e recupera a miniatura PNG original quando disponível. O documento não é alterado. Nenhuma tabela ou registro SQLite é modificado.

2. Como usar

  1. Execute wmk-data-studio.cmd e abra http://127.0.0.1:3366/.
  2. Clique na aba Importação WMK Studio no topo.
  3. Escolha um documento .wmk. Para testes, use laboratorios/wmk-design-to-app/ridgeline-web-poc/ridgeline-laboratorio.wmk.
  4. Clique Ler projeto WMK.
  5. Escolha um Frame no painel Telas disponíveis. A prévia exibe textos, preenchimentos, posições e algumas formas.
  6. Selecione uma camada na árvore para destacá-la. Abra Miniatura original salva no arquivo para ver a imagem do documento.

3. Fidelidade visual e limitações

InformaçãoResultado
Nomes, IDs e ordem de camadasExtraídos do documento original
Textos, dimensões e preenchimentosPrévia experimental HTML/CSS
Polígonos vetoriaisReconstrução SVG aproximada
Miniatura PNGOriginal salva no arquivo, não captura por Frame
Curvas, máscaras, instâncias, tipografia e Auto LayoutAinda não são reproduzidos fielmente

4. Segurança e verificação

O importador limita o upload a 12 MB e document.json descompactado a 10 MB. O parser não extrai arquivos nem executa instruções do projeto; a rota exige token local. O arquivo importado fica em memória para prévia e não é gravado pelo servidor.

Testes concluídos com documento real: 349 nós, três telas, miniatura, HTTP 200 na importação, rejeição de arquivo inválido e chamada sem token; JavaScript do visualizador passou na checagem sintática. A fidelidade do desenho ainda requer validação com screenshots no navegador.

5. Próxima integração

Selecionar um nó da prévia, escolher uma entidade e campo SQLite (DataField), configurar eventos no Behavior Inspector e gerar formulários React/TypeScript com API. Para visualização totalmente fiel, será necessário integrar o renderizador do WMK Studio.
