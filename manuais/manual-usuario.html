1. O que é FigCraft?

O FigCraft é um editor de design de interfaces e protótipos com foco em arquivos locais. Seu formato nativo usa a extensão .figcraft. O repositório descreve importação e exportação em formatos como SVG, PNG, JPG, WebP e PDF, além de abertura experimental de arquivos .fig.

O projeto se apresenta como alpha. Este manual descreve recursos documentados no código-fonte; não significa que todos foram validados na compilação WMK. Salve cópias de projetos importantes e espere limitações.

Primeira execução

  1. Instale ou obtenha uma versão executável verificada do FigCraft.
  2. Abra o aplicativo e procure o menu de preferências/configurações.
  3. Em Preferences → Language, selecione Português (Brasil), se disponível.
  4. Crie um documento novo e salve com extensão .figcraft.
  5. Teste a abertura do arquivo salvo antes de realizar trabalhos importantes.

A localização exata dos controles deve ser validada na interface do fork compilado; os nomes podem mudar entre versões.

3. Exercício: sua primeira tela

  1. Crie um documento chamado primeiro-layout.figcraft.
  2. Adicione um quadro/tela para uma interface de aplicativo.
  3. Insira um título, um botão e uma área de conteúdo.
  4. Organize as camadas com nomes claros, como Cabecalho e Conteudo.
  5. Configure cores e espaçamentos consistentes.
  6. Salve o arquivo e feche o aplicativo.
  7. Abra novamente o documento e confira os elementos.
  8. Experimente exportar a tela para PNG ou SVG e compare o resultado.

Boas práticas

Salve versões intermediárias, mantenha nomes descritivos para camadas, organize recursos por projeto e confirme se as exportações preservam fontes, cores e efeitos.

4. Dúvidas frequentes

A interface aparece em inglês

O código-fonte contém crates/ui-egui/locales/pt-BR.toml. Consulte Preferences → Language. Caso existam trechos em inglês, eles podem representar chaves sem tradução. O guia técnico explica como corrigi-los.

Não consigo abrir um arquivo .fig

O README descreve suporte de importação em caráter best effort, ou seja, sem garantia de compatibilidade integral. Preserve o original e teste com uma cópia.

Um recurso não funciona

Registre a versão do aplicativo, sistema operacional, etapas para reproduzir, comportamento esperado, resultado observado e, se possível, uma captura de tela. Evite publicar documentos pessoais ou dados confidenciais em relatórios públicos.

O programa não abre

Verifique se o executável foi realmente compilado, se a instalação possui recursos necessários e se existem mensagens de erro. Para compilar a partir do código-fonte, consulte Manual de compilação Windows.
