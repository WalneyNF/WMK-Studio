WMK Data Studio v0.1 — SQLite visual

Crie tabelas, campos e registros; exporte o esquema e gere aplicativos React/TypeScript

Walney Moreira Klein — walneyk@hotmail.com | 08/11/2026

Central de manuais | CRUD com SQLite

1. Conceito

O Bubble usa PostgreSQL e uma aba visual Data para administrar tipos, campos e registros. Nosso laboratório WMK Data Studio oferece modelagem visual com SQLite, banco local e exportação de entidades para o WMK App Bridge. Não é uma cópia da interface do Bubble e não está integrado ao executável WMK Studio nesta versão.

2. Como executar

cd D:\Ferramentas\figcraft
wmk-data-studio.cmd

Abra http://127.0.0.1:3366/. O banco físico é criado em tools/wmk-data-studio/data/wmk-studio.sqlite. Encerre com Ctrl+C no terminal.

4. Exercício: cadastrar clientes

  1. Crie a tabela clientes com descrição Cadastro de Clientes.
  2. Adicione nome (Texto, obrigatório), email (E-mail), telefone (Texto) e ativo (Booleano).
  3. Cadastre registros fictícios, altere, pesquise e exclua. Reinicie o serviço e confirme a persistência.
  4. Clique Exportar modelos JSON e salve wmk-data-models.json.

5. Gerar aplicativo real a partir do modelo

python tools\wmk-app-bridge\export.py "meu-design.wmk" --bindings "meus-bindings.json" --models "wmk-data-models.json" --out "D:\Projetos\app-clientes"
cd D:\Projetos\app-clientes
npm install
npm run build
npm run dev:full

O App Bridge cria um manifesto com os campos modelados; o backend Node.js cria as tabelas SQLite do aplicativo exportado. O banco do editor e o banco do aplicativo são separados. O esquema é exportado, mas os dados gravados não são copiados automaticamente.

6. Testes realizados

Foram verificados CRUD e persistência SQLite, reabertura do banco, rejeição de campos inválidos, sintaxe JavaScript da interface, API HTTP local com token de mutação e exportação do JSON para o App Bridge. O projeto de saída foi criado e seu manifesto contém a entidade clientes. A renderização e os cliques da interface ainda não passaram por teste end-to-end em navegador.

7. Segurança e evolução

Laboratório para desenvolvimento local apenas. Escuta em 127.0.0.1, mas não possui login, autorização por tabela nem sistema de backup. Não disponibilizar na internet ou inserir dados sensíveis. Próximas etapas: editor de relacionamentos, índices, migracoes, backup, opções, regras de privacidade e uma aba Banco de Dados diretamente na interface do WMK Studio.
