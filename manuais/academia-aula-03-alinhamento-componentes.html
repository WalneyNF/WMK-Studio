Aula 3 — Alinhamento, camadas e primeiro botão

Esta aula dá continuidade ao projeto Cartão WMK, iniciado nas aulas anteriores. Também documenta os aprendizados observados nas capturas enviadas pelo mantenedor: inserção de três textos, escolha de fontes e abertura da janela de prévia.

O que já aprendemos

Frame 600 × 300 px, fundo #1B0736, título WMK Studio, subtítulo Design • Tecnologia • Criatividade e descrição Meu primeiro projeto de design visual.. O painel de Camadas mostra os três textos dentro do Frame.

Na prévia, o Frame pode parecer menor porque a janela de apresentação utiliza uma escala diferente. Não confunda escala de visualização com dimensões reais.

1. Hierarquia visual: títulos e textos

Hierarquia visual é a diferença planejada de importância entre os elementos. O título deve ser o maior texto; o subtítulo, menor e em cor de realce; a descrição, discreta e legível.

ElementoCorTamanho sugerido
Título#F5E9FF28–32 px
Subtítulo#E6B3FF15 px
Descrição#F5E9FF16 px

Uma família como Inter funciona bem nos três. Pesos diferentes (Regular, Medium, Bold) são preferíveis a misturar muitas famílias de fontes. Esses valores são sugestões para estudar, não restrições do aplicativo.

2. Alinhando os textos com precisão

  1. Na árvore Camadas, clique no título.
  2. Na área Posição do painel Design, localize as coordenadas X e Y. Dentro de um Frame, X/Y podem ser relativas ao contêiner.
  3. Experimente X = 24 e Y = 24.
  4. Selecione o subtítulo e defina X = 24, colocando o texto logo abaixo do título com espaço de aproximadamente 10 px.
  5. Selecione a descrição e aplique o mesmo X = 24, deixando espaço para respirar.
  6. Confira no Canvas se o texto não está cortado. Ajuste se necessário, considerando a altura real de cada camada.

Os controles de alinhamento horizontal e vertical no painel Design podem ajudar a distribuir objetos selecionados, mas não substituem a decisão sobre margens.

3. Criando um botão visual

  1. Selecione a ferramenta Retângulo na barra inferior. Desenhe uma forma dentro do cartão.
  2. Defina aproximadamente 180 × 42 px e preenchimento #8A2BE2.
  3. Se existir a propriedade Raio do canto, experimente 8 px para suavizar as bordas.
  4. Selecione Texto e escreva Conhecer projeto.
  5. Escolha 15 px, cor #FFFFFF, preferencialmente em seminegrito.
  6. Centralize o texto no retângulo. No painel Camadas, renomeie os objetos para Botão - fundo e Botão - texto.

O botão é apenas visual. Para fazer o clique navegar entre telas, usaremos Protótipo em aula posterior.

4. Entendendo os grupos e componentes

Agrupar organiza objetos para movê-los juntos; Componente permite reutilizar um elemento em múltiplas partes do documento. No menu contextual observado nas capturas do editor, aparecem Agrupar seleção (Ctrl+G) e Criar componente (Ctrl+Alt+K).

  1. Com a ferramenta de seleção, escolha o retângulo e o texto do botão.
  2. Use Ctrl+G para agrupá-los, observando o agrupamento na árvore de camadas.
  3. Para estudar componentes, selecione o conjunto criado e procure Criar componente no menu contextual (ou use Ctrl+Alt+K).
  4. Observe a aba Recursos e teste uma cópia/instância do elemento, se o aplicativo apresentar essa opção.

Se a seleção envolver camadas que não pertencem ao mesmo Frame, confira a hierarquia antes de agrupar.

6. Exercícios opcionais para alunos

  • Redimensionar o botão sem deformar o texto.
  • Usar a mesma margem esquerda para os três textos.
  • Renomear todas as camadas.
  • Agrupar fundo e texto do botão.
  • Testar uma cópia do grupo e comparar com um componente reutilizável.

Questão: qual é a diferença entre um Frame e um Grupo? Resposta: Frame é contêiner de layout/desenho, com dimensões, preenchimento e recorte próprios; Grupo reúne camadas para organização e transformação conjunta.

Registros e limitações

As capturas que fundamentaram esta aula mostram os textos dentro do Frame, o menu de contexto com atalhos, o painel de tipografia e a prévia aberta. Não provam, por si só, que agrupamentos, componentes ou exportações foram testados. Estes exercícios são instruções a reproduzir, não resultados certificados.
